# 幻语 · 角色扮演对话

> 当前版本 **v1.3**（v1.0 基础版 → v1.1 世界线分支 / 私谈场景 / 知识图谱 / 世界导入导出 → v1.2 技能库 2.0 · 杀八股去AI味 → v1.3 **技能商城**：11 大分类 67 个内置技能 · 勾选上架 · 自定义自由扩展）

一个豆包 / Grok 风格的**手机优先** AI 角色扮演应用：既可以和单一角色对话，也可以**创造属于自己的异世界**——在世界中冒险，由 AI 叙事者（GM）推动剧情、触发事件、遇到形形色色的人物。纯前端实现（零依赖、零构建），数据全部保存在本机浏览器中。

## ✨ 两种玩法

**🌍 世界冒险**——你扮演「你」，在异世界中活动：

- 创造不同的世界，各自定义**世界规则 / 世界观**、开场剧情、初始玩家状态（金币、生命……）；角色与世界都支持**上传图片头像**；
- 每个世界有自己的**角色名册**：可手动添加，也会在冒险中**遇到新人物时由 AI 自动生成角色卡**（可随时编辑）；
- 你说想做什么（「走进酒馆」「向她打听消息」），AI 以小说笔法叙述世界的变化：旁白 + 各 NPC 的对白（带头像气泡）；**NPC 之间也会相互交谈、拌嘴、配合**（由你的言行触发，按顺序逐个成泡）；
- 触发事件、场景与时间的推移、玩家状态的增减，顶部状态栏实时显示；
- **世界线分支**：在任意剧情处分支出平行世界线，不同的选择得到不同的结局；消息、状态、记忆各自独立，随时回到主线，主线不受影响；
- **世界导出 / 导入**：单个世界（含规则、名册、知识图谱）一键打包为 JSON，方便备份与分享。

**💬 世界角色私谈**——与世界里某个角色单独面对面：

- 按**常在地点**自动生成相符的场景（老板娘在酒馆吧台、学者在书房……），角色会用动作描写体现场景，场景随对话自然切换；
- 共享世界知识图谱：你在世界里做过的事 TA 都记得，私谈里的秘密也会**带回大世界**（对应角色在后续冒险中记得你们之间的约定）。

**🎭 单角色对话**——与一位角色面对面聊天（原模式完整保留）。

### 世界冒险的输出协议（技术细节）

AI 的叙事按以下约定生成，应用据此渲染并维护世界状态：

- NPC 对白独立成行：`名字：「台词」` → 渲染为该角色头像的对话气泡；
- 回复末尾可附带状态块：`⟦STATE⟧{"location":"…","time":"…","events":[…],"present":[…],"status":{…},"newCharacters":[…]}⟦/STATE⟧` → 应用解析后更新场景坐标、状态栏、事件卡片，并把新角色写入世界名册；状态块不会显示在对话中。

## 🚀 快速开始

**方式一（推荐）：本地服务器**

```bash
node server.js
```

打开 `http://localhost:3000`；手机连同一 WiFi，访问启动时打印的局域网地址即可。

**方式二：静态托管**

把整个文件夹丢到任意静态服务器（Nginx / Vercel / GitHub Pages…）即可。

**方式三：直接打开**

双击 `index.html` 也能运行（演示模式可用；接入真实 API 时若遇 CORS 问题请改用方式一并开启代理）。

## 🔌 接入你自己的模型

进入左侧抽屉 → **后台设置**：

1. 接口模式切换为 **自定义 API**；
2. 填写 **API 地址**（OpenAI 兼容，如 `https://api.deepseek.com/v1`、`https://api.openai.com/v1`、各类中转站地址）；
3. 填写 **API Key** 与 **模型名称**；
4. 按需设置**思考强度**（o 系列 / DeepSeek-R1 等推理模型建议「中」或「高」）；
5. 点击 **测试连接** 验证。

> **跨域(CORS)报错？** 用 `node server.js` 启动，并在设置里打开「通过本地代理转发」，请求将由本地服务器转发，彻底绕开 CORS。

> Key 只保存在你本机浏览器的 localStorage 中，不会上传到任何服务器。

## 🧭 使用技巧

- **开启冒险**：抽屉「对话」页或右上角 ＋ → 选择「世界冒险」或「单角色对话」；
- **世界冒险**：直接说想做的事即可，如「观察四周」「走进酒馆点一杯酒」「向她打听北边古塔的事」；消息中提到遇到陌生人，AI 可能为你生成新角色；
- **世界面板**：点击顶部世界名称 → 编辑世界规则、当前场景、**角色名册**（含 AI 自动生成的角色卡）、附加技能，或重新开始这段冒险；
- **重命名**：长按会话（手机）或右键 / 悬停 ⋯（电脑）→ 重命名；
- **单角色扮演**：角色的「人设提示词」写越细越传神（身份、口癖、世界观、动作描写要求）；配合「细节描写增强」技能效果更佳；
- **文笔优化**：觉得 AI 味重就勾上「杀八股 · 去AI味」；嫌 AI 抢话就加「防抢话」；嫌复读就加「反复读机」——品质约束类技能可长期挂在对话上；
- **文风混搭**：文风类技能（网文爽感、轻小说、鲁迅白描…）与题材氛围类（哥特恐怖、赛博霓虹…）可叠加，如同给对话调了一套预设；
- **技能商城**：技能太多找不到？侧栏只留常用的，其余在「🛍️ 技能商城」里按分类勾选上架；支持「全上架 / 全下架」一键整理；
- **思考过程**：回复上方的「深度思考」卡片可折叠，流式阶段会显示实时思考内容与用时；
- **消息操作**：点击气泡旁的按钮可复制 / 编辑 / 重新生成 / 删除；「保存并重问」会基于编辑后的内容重新生成。
